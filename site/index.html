Type Arabizi. Get Arabic.

Harfi turns Lebanese Arabizi into Arabic as you type, in every app on your Mac or Windows PC. Privately: nothing you type ever leaves your computer.

What's new

Why Harfi

It speaks Lebanese

Trained on how people really text: Shu bdk t3ml bara becomes شو بدك تعمل برا, and your English stays English.

Private by design

The conversion runs on your own computer, with no internet needed. No account, no tracking, no cloud.

Fix a word in a tap

See the Arabic as you type, press ↑ to fix a word before sending, and Harfi remembers your spelling.

Install

Mac

Open Terminal (press ⌘ Space, type Terminal), paste this line and press Enter:

curl -fsSL https://raw.githubusercontent.com/Mustafa-Abbara/arabizi-keyboard/main/scripts/install_harfi.sh | bash
  1. It installs Harfi and downloads its model (808 MB). If your connection drops, it carries on where it stopped.
  2. Turn it on once: System Settings → Keyboard → Input Sources → Edit… → + → Arabic → Harfi.
  3. Switch to it with Ctrl Space and type.

Why Terminal? See the questions below. Full guide

Windows Preview

On a 64-bit Windows 10 or 11 PC:

  1. Download Harfi for Windows, then right-click the zip → Extract All.
  2. In the extracted folder, double-click Install Harfi and press Install. It installs Harfi for you only and downloads its model (808 MB, each part checked); if Windows asks for administrator rights, allow it once.
  3. Turn it on once: Settings → Time & language → Language & region → Arabic (Lebanon) → Language options → Add a keyboard → Harfi. Add Arabic (Lebanon) first if it isn't listed.
  4. Switch to it with Win Space and type.

Harfi in the Start menu has the settings, the words you taught it and the keys.

The model runs on the processor, so the first conversion after starting takes a few seconds. Full guide

Windows

Enter
Your text becomes Arabic. Enter again sends.
↑
Fix a word, before converting or right after: ← → choose the word, a number picks its spelling.
Esc
Keep what you typed in Latin.
Ctrl Z
Your Latin text back, right after converting.
Alt Enter
Convert the text you selected.

Questions

Is it really private?

Yes. What you type is converted on your own computer and never sent anywhere: no account, no analytics, no cloud. On the Mac the model runs in a sandbox with no network access. The only download is the model itself, once, from GitHub. Harfi keeps only the single words you correct, encrypted and on your computer, for 30 days, so your spelling comes first next time. Password fields are never touched.

Why is the download 808 MB?

That's the conversion model: a fine-tuned Llama 3.2 1B that runs on your computer instead of on a server. It's downloaded once and checked, and the download resumes if your connection drops.

Why Terminal on the Mac?

Harfi is free and isn't signed with a paid Apple Developer ID, so macOS would block a normal download. The install line downloads it and signs it on your own Mac instead, which macOS accepts.

Windows warns me or asks for administrator rights. Is that safe?

Harfi isn't signed with a paid certificate, so Windows may say it doesn't know the publisher when you open Install Harfi: choose More info → Run anyway. Adding a keyboard to Windows needs administrator rights once; everything else installs for your account only. The code is open on GitHub for anyone to check.

Which apps does it work in?

Any app where you type with the system keyboard: WhatsApp, Instagram and other sites in your browser, Word, Notes, Notepad and more. Password fields are left alone.

What does my computer need?

Mac: Apple silicon (M1 or later) with macOS 14 or later. Windows: a 64-bit PC with Windows 10 or 11. Harfi needs about 1 GB of disk space, and the model uses about 1 GB of memory while you type; on Windows it's freed after half an hour without typing.

It isn't converting.

Check that Harfi is the selected keyboard (Ctrl Space on the Mac, Win Space on Windows). After installing or updating, restart the app you're typing in: apps keep the version they loaded. On Windows, status.ps1 in the folder you extracted shows which apps use Harfi and whether its model is ready. Still stuck? Open an issue on GitHub and describe what you typed, without pasting private messages.

How do I update?

Mac: run the install line again. Windows: download the latest zip and run Install Harfi again. The model is only downloaded again if it changed.

How do I remove it?

Mac: run this in Terminal, then remove Harfi from Input Sources (−). The words Harfi learned stay until you choose Forget all my words in its window first.

curl -fsSL https://raw.githubusercontent.com/Mustafa-Abbara/arabizi-keyboard/main/scripts/install_harfi.sh | bash -s -- --uninstall

Windows: Settings → Apps → Installed apps → Harfi → Uninstall. This also removes the words Harfi learned.

Is it free?

Yes, free and open source. Harfi is a student project, and its code and how the model was trained are on GitHub.
