# Harfi's voice and look

Harfi sounds like a friend who types fast: warm, short and plain, never childish and never corporate. Personality shows in small moments and never gets in the way of typing.

## Words

- Sentence case everywhere; no full stop on labels and buttons, one on sentences.
- Short sentences, plain words: older and non-technical people read every screen.
- No "please", no "successfully", no exclamation marks on system text, no jargon (model, engine, IME, token).
- Speak about the user's things as "your" ("Your words"); confirmations need no subject ("Got it").
- Say what happened and what to do next; never blame the user.
- Lebanese touches stay light: the time-of-day greeting (صباح الخير, مساء الخير) and Arabic examples. No stereotypes.
- Personality follows the setting: Full (greetings, small touches), Calm (friendly words only), Quiet (essentials only).

| Moment | Say |
|---|---|
| Installed | You're all set. Type away. |
| First run | Welcome. Let's try it once. |
| Practice | Each step ticks by itself when you do it. |
| After converting | Not quite? ⌥Tab to fix a word |
| In the preview | ↑ fix a word |
| A fix is remembered | Got it. Next time `l7al` will be الحال. |
| Model still loading | Warming up. Your first message is on its way. |
| No model yet | Harfi uses its rules for now. |
| Privacy | Everything happens on your Mac. Nothing you type is sent anywhere. |
| Empty "Your words" | Teach Harfi your spellings |
| Forget all | Harfi will stop putting your spellings first. This can't be undone. |
| Download dropped | Connection dropped, resuming in 3 s... |
| Damaged download | The download is damaged. Try again. |
| Not in Input Sources | If Harfi is not in the list, log out and back in once. |

## Look

- Colours: Cedar and sand, `design/palette.json` (Swift: `Theme`). One accent (cedar); amber only for "this word looks wrong". Stronger values when Increase contrast is on.
- Arabic: Noto Naskh Arabic (SIL OFL 1.1, `Apps/ArabiziIME/Resources/Fonts`), 22 pt in the preview and 20 pt in chips; "Larger text" scales both by 1.3.
- Shapes: rounded boxes (10 pt), 1 pt borders, no heavy shadows; click targets at least 32 pt.
- Motion: short (0.12 to 0.18 s) fades and glides that show where the eye should go; none when Reduce motion is on.
- Accessibility: every control has a VoiceOver label, every shortcut has a visible button or chip.
